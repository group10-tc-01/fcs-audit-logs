# FCS Audit Logs

O FCS Audit Logs consome eventos de auditoria do Kafka e persiste registros imutáveis no MongoDB.

## Operação

- Namespace Kubernetes: `fcs-audit-logs`
- Health check: `/health`
- Métricas: `/metrics`

Consulte o [README](../README.md) para requisitos, execução local e contrato do evento de auditoria.
